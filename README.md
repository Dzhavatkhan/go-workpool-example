# Go Worker Pool - Учебный проект
Реализация паттерна  Worker Pool на Golang с использованием горутин, каналов и контекста.

## Что внутри?

Проект демонстрирует:
- параллельную работу нескольких воркеровж
- синхронизация через `sync.WaitGroup()`;
- управление жизненным циклом воркеров через `context.WithCancel`;
- передачу данных по каналам `chan`;
- защита от гонок данных с помощью атомарных операций и Mutex.
